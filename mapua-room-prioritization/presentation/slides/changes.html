Session 1 ranked courses but could not say when or where a class meets, so two sections could be given the same room at the same time. It also ignored campus and counted students who were not yet eligible. v2 fixes all three, moves the weights into a settings file, computes the KPIs every run and adds nine tests that guard the hard rules. Open CHANGELOG.md in the repo if anyone wants detail.
