MAPÚA UNIVERSITY · ROOM UTILIZATION · SESSION 2

Too many sections, too few of the right rooms

An offering-prioritization engine that ranks every course offering, then books real rooms and times, highest priority first. Built from Curriculum, Courses, Rooms and Enrolled Students data.

View the 5-slide deck Download PDF Source on GitHub

How it works

1

Forecast demand

Per course and campus. Only students who passed the prerequisites count.

2

Score priority

Six weighted factors: graduating share, bottleneck, needs a lab, demand, required, scarcity.

3

Timetable

Mon–Sat 3-hour blocks. Right room type, campus and size. No double-booking.

4

View and report

Ranked view, section schedule, room timetable, KPIs and a shareable report.

When rooms run out, each section falls back in this order:

Prime-time room›Online, if allowed›Evening/Saturday room›Unmet + reason
